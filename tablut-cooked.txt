2. How to run the player from the command line
   /home/tablut/tablut/runmyplayer.sh <ROLE> <TIMEOUT> <SERVER_IP>

   - ROLE: WHITE or BLACK (case-insensitive). WHITE connects to port 5800, BLACK to port 5801.
   - TIMEOUT: seconds allowed per move (positive integer, may be lower than 60).
   - SERVER_IP: IP address of the referee server (not hardcoded to localhost).

   Example:
   /home/tablut/tablut/runmyplayer.sh WHITE 60 192.168.20.101

   The script runs the player with "uv run" from the project folder. The VM has no
   internet access during the tournament, so all dependencies (see uv.lock) must be
   installed in the VM beforehand.
